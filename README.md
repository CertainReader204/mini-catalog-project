# Proje Adı: Software Persona E-Commerce

# Kısa Açıklama: 
Software Persona E-Commerce, Flutter kullanılarak geliştirilmiş bir mobil mini katalog uygulamasıdır. Kullanıcıların ürünleri görüntüleyebilmesini ve uygulama içerisindeki temel e-ticaret işlemlerini gerçekleştirebilmesini amaçlamaktadır.

# Kullanılan Flutter sürümü: 3.41.6

# Çalıştırma Adımları:
1. Repository'yi bilgisayarınıza klonlayın.
2. Proje klasörünü VS Code veya Android Studio ile açın.
3. Terminal üzerinden gerekli Flutter paketlerini yüklemek için aşağıdaki komutu çalıştırın:

flutter pub get

4. Bir Android emulator veya fiziksel Android cihaz başlatın.
5. 'lib/main.dart' üzerinden kod alanının üzerinde bulunan Run/Debug butonlarından uygulamayı çalıştırın.
6. Terminal üzerinden çalıştırmak için aşağıdaki komutu çalıştırın:

flutter run
